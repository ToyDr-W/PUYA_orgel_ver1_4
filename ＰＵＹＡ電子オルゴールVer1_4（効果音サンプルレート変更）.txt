【前振り】

先日は、ドライブハンドルのマイコン換装で必要となった機能で、音符の演奏で効果音を発生する機能をＰＵＹＡ電子オルゴールに実装した。これを使って、ハンドル部の換装用ファームウェアを開発した。

その次の課題として、ドライブハンドルのペダル部の換装用ファームウェアの開発がある。ペダル部にはアクセルペダルがあり、エンジン音を低速～高速で変化させる必要がある。効果音の「音程」を滑らかに上下させるにはどうすればよいか、ということだ。


【設計】

①設計の対象は、ＰＵＹＡ３２・ＳＴＭ３２・ＣＨ３２Ｖの電子オルゴールとし、ＰＩＣ電子オルゴールは新規の機能改善を終了しているため対象外とする。なお、現時点ではＰＵＹＡ電子オルゴールのみ対応済み。

②「音程」を変える方法は、ＤＤＳでの位相角を変化させるのと同じだ。

・音源のサンプルをサンプリング周期で一つずつ進めると、元の音源の「音程」で再生される。

・多めに進めると「音程」は高くなり、少なめに進めると「音程」は低くなる。

③滑らかに変化させるために、サンプルを進める量（コードでは「飛び数」と表現）は１／２５６の精度で管理する。

④「飛び数」をリアルタイムに変化させるＡＰＩを提供する。


【実装】

①音声Ｎインデックスの書式は従前どおりだが、サンプリングレートを「飛び数」に変換するようにマクロを変更した。

（変更前）
//==============================================
//音声ｲﾝﾃﾞｯｸｽ(VOICE_N用)生成ﾏｸﾛ

//aaa:音声ﾃﾞｰﾀのｱﾄﾞﾚｽ[ﾊﾞｲﾄ]､bbb:長さ[ﾊﾞｲﾄ]､sss:ｻﾝﾌﾟﾘﾝｸﾞﾚｰﾄ[sps]

//音声ｲﾝﾃﾞｯｸｽ(VOICE_N用)生成ﾏｸﾛ

//aaa:音声ﾃﾞｰﾀのｱﾄﾞﾚｽ[ﾊﾞｲﾄ]､bbb:長さ[ﾊﾞｲﾄ]､sss:再生ｻﾝﾌﾟﾘﾝｸﾞﾚｰﾄ[sps]
//==============================================
#define　von_mac(aaa,bbb,sss)　{aaa,bbb,(unsigned long)256*sss*PWM_PR/1000000},

//==============================================

static unsigned short smp=4000;　　　//ｴﾝｼﾞﾝ音のｻﾝﾌﾟﾙﾚｰﾄ[sps]

　RCC->APBENR2|=RCC_APBENR2_SYSCFGEN;　//SYSCFGにｸﾛｯｸ供給

　VOICEN_SEL(0,1);

//==============================================
//固有の処理(ｺｰﾙﾊﾞｯｸ関数)
//
//動作仕様
//・ｴﾝｼﾞﾝ音は音声N0
//
//音声
//1.ｱｲﾄﾞﾘﾝｸﾞ
//==============================================
static void CB_KOYUU(void)
{

　if(GPIO_R(SW0_GPIO,SW0_BIT))
　{
　　if(smp>4000) smp-=200;
　}
　else
　{
　　if(smp<15000) smp+=500;
　}
　VOICEN_SMP(0,smp);　　//ｻﾝﾌﾟﾙﾚｰﾄを設定する
DBG_C('>');
}

　unsigned char ch)　　　//音声Nのch番号

　//ｴﾝｼﾞﾝの制御

　　VOICEN_SEL(0,1);　　//定常音を連続再生する
　　VOICEN_SMP(0,smp);　　//ｻﾝﾌﾟﾙﾚｰﾄを設定する
